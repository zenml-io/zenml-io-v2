# ZenML Labs shell and the 2026 rebrand cutovers

Every page family that has moved onto the ZenML Labs shell on the
`rebrand/labs-site` branch: the shell + homepage, blog, research databases,
product one-off pages, integrations + features, and get-started routing.
DESIGN.md holds the binding design rules; `src/components/labs/` holds the
components. Read the section for the family you are touching before editing.
